アプリを起動

軽量な 2D 作図アプリ。

レイヤー、寸法、複数ページの投影図に対応します。PDF や SVG への出力もできます。必要なら、図面から 3D プレビューや STL 出力も。AI（エージェント）を MCP で接続し、作図や確認作業を補助できます。

アプリを起動 ドキュメント

インストール不要。ログインも不要です。

2D 作図

図形、レイヤー、寸法線。Undo 付きの SVG キャンバス。

複数ページ

上面図・正面図など、ページごとに管理。

3D プレビュー

投影図が揃えば立体化。STL 出力も可能。

AI エージェント連携

MCP でエージェントを接続し、図面作成・寸法追加・3D化前の確認を補助できます。
